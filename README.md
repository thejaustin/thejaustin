## About

I build open-source Android tools, mostly around Shizuku, Dhizuku and Samsung One UI.  
Many of my projects begin as forks of apps I use and want to extend.

I write Kotlin and Jetpack Compose day to day, with some Flutter.  
Most of the work is built and tested on my phone, with AI coding assistants.  
I review everything before it ships.

<br/>

## Current Work

The Mini Blocks mod, rebuilt as a Bedrock add-on.
