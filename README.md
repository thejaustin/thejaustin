# Austin

Android developer. I build open-source tools for Shizuku and Samsung One UI.

[Website](https://thejaustin.github.io) · [Stats](https://thejaustin.github.io/thejaustin/) · [Sponsor](https://github.com/sponsors/thejaustin) · [Buy me a coffee](https://buymeacoffee.com/thejaustin)

## About

I write Kotlin and Jetpack Compose, with some Flutter.
Most projects start as forks of apps I use and want to extend.
I develop on my phone with AI coding assistants and review everything before it ships.
